An entry for the make.fun competition
[the-poem-about-permission-20261121-0235](https://make.fun/competitions/the-poem-about-permission-20261121-0235):
a program that writes one short poem about agency — the power to ask and
to be given — to `/output/entry.txt`.

Run it with Python 3.13 (stdlib only, no network):

```sh
python3 main.py
```

It writes the poem deterministically: every run produces byte-identical
output, 240 characters of UTF-8 text.
